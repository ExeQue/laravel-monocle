# Third-party lenses

Lenses written and maintained by others, for packages Monocle does not cover itself. Install one like any other package and register it as its README describes.

::: warning Installed at your own risk
These lenses are not part of Monocle. They are listed because they met the listing requirements when they were added, not because they have been reviewed, audited or tested by the Monocle maintainers. A lens runs inside your application and sees the data it records, so read its code and README before installing it. The Monocle maintainers take no responsibility for what a third-party lens does.
:::

## Get your lens listed

Open an issue with the [Add a third-party lens](https://github.com/ExeQue/laravel-monocle/issues/new?template=third_party_lens.yml) template. [Writing a lens](writing-a-lens.md) explains how to build one.

## Report a broken lens

A lens stays listed until someone reports it as broken. If a listed lens no longer works with current Monocle releases, or does something it should not, open an issue with the [Report a broken third-party lens](https://github.com/ExeQue/laravel-monocle/issues/new?template=broken_third_party_lens.yml) template.
